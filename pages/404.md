你来到这个页面，通常有两个原因。

## 一、链接错误

原因：博客搬迁造成的旧链接失效。

例子：某篇文章的旧链接是

```
http://ylcs-mm.github.io/old-path/some-article/
```

请修改成

```
https://ylcs-mm.github.io/new-path/some-article/
```

**备用办法：** 在「[分类](/categories/)」中找。

## 二、维度攻击

不明力量入侵，你想要访问的页面被摧毁了。
