🐾 🌸 博客全面焕新升级喵！ 🐾
【2026-10-11】

窝们换引擎啦！从 Jekyll 到 Hugo 喵～ 🚀

经过一段时间的努力，博客完成了自上线以来最大规模的一次重写喵！

🏗️ 底层重构

  • Jekyll → Hugo：静态站点生成器全面迁移，构建速度从秒级进化到毫秒级（77ms 完成构建！）
  • 模板体系从 Liquid 迁移到 Go Templates，代码结构更清晰喵

🎨 界面全面焕新

  • 全新的甘城猫猫风格配色系统：粉蓝渐变 + 半透明毛玻璃效果，像棉花糖一样柔软
  • 统一的 CSS 变量设计体系，全站视觉一致性大幅提升
  • 所有页面独立重写美化：首页、文章页、公告页、关于页、列表页
  • 英雄区星光漂浮动画、头像悬停发光、卡片毛玻璃 hover…
  • 引用块引号装饰、代码块渐变顶部条、表格斑马纹…细节满满喵！

📱 全端响应式适配

  • 覆盖 5 个断点：手机（320px+）、平板、桌面、宽屏、超宽屏
  • 手机端和桌面端都能获得最佳浏览体验

🐾 看板娘搬家

  • 猫猫看板娘从中间移到了右下角固定显示
  • 桌面端 160×320，手机端自动缩小为 110×220
  • 不再遮挡正文内容，随时可rua！

📊 统计系统升级

  • 从「不蒜子」更换为 Umami Cloud，统计更稳定精准喵～

🧹 其他优化

  • 移除了评论组件，页面更清爽
  • 代码整体瘦身，加载速度更快
  • 键盘导航优化，无障碍访问体验提升
